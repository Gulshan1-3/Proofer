ProofArena

A real-time 1v1 theorem proving battle platform built with Rust and Lean.

Players compete head-to-head to solve formal proofs as fast as possible.
The platform validates proofs using Lean and determines the winner based on correctness and completion time.

Features
Real-time 1v1 proof battles
Lean proof verification
Matchmaking system
Timed proof challenges
Live opponent status updates
